# Viridian

Dark petrol and mineral sage from the Logis HUD tile: background `#10252A`,
accent `#9BBEB5`, steel blue `#91AFBB`, and text `#E1ECE8`. ANSI status colours
stay muted but distinct. The wallpaper is the original Logis HUD artwork.

- `theme viridian` applies the desktop theme.
- `viridian` in Fish recolours the current terminal or Herdr pane.
- `theme-term.sh viridian` recolours the focused Kitty window.

Neovim uses Nord with its existing transparent background; Obsidian uses
Minimal. Desktop surfaces use the quiet effects profile, matching Silver.

`palette.yaml` is the initial Base16 scaffold. `theme.json` and the surface
files contain the final sage accent, cursor, selection and border adjustments.
